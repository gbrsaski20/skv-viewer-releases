## 📲 Cara Install

1. **Unduh** file `SKV-Valorant-Viewer.apk` dari tabel di atas
2. Buka file unduhan tersebut
3. Kalau muncul peringatan **"Install unknown apps"** → tap **Pengaturan** → aktifkan **Izinkan dari sumber ini**
4. Tap **Install**, tunggu sampai selesai
5. Buka **SKV Valorant Viewer** dari daftar aplikasi

## 🔑 Lisensi & Akun VIP

Aplikasi ini memakai sistem **license key**:

- Beli paket → dapat license key (1 paket = 3 slot akun)
- Buka aplikasi → **Membership VIP → Aktivasi license key**
- Key akan tersimpan di HP, install ulang tetap aktif selama ketik ulang key-nya
- Login Discord bersifat **opsional** (untuk anti-share & memudahkan saat ganti HP)

Pembayaran via **QRIS**. Harga dan info paket ada di halaman VIP dalam aplikasi.

## ❓ FAQ

<details>

<summary>Apakah aplikasi ini aman dipakai?</summary>

Aman. Aplikasi memakai **login resmi Riot Games** (halaman login Riot asli),  
bukan input username/password ke pihak ketiga. Data login tidak dikirim ke server kami.

</details>

<details>

<summary>Key saya tiba-tiba tidak bisa dipakai?</summary>

Buka ulang aplikasi — status key dicek otomatis dari server. Kalau key sudah dibanned  
atau kadaluarsa, aplikasi akan menampilkan layar notifikasi. Hubungi owner lewat Discord  
kalau menurutmu ini keliru.

</details>

<details>

<summary>Akun saya tidak masuk ke "Manage Akun"?</summary>

Akun yang login **sebelum** memasukkan license key otomatis terhitung begitu key diaktifkan —  
tidak perlu tutup-buka aplikasi. Kalau tetap belum muncul, coba tarik-refresh halaman Manage Akun.

</details>

<details>

<summary>Update aplikasi lewat mana?</summary>

Cukup install APK versi terbaru dari repo ini (nonton tab Releases). Atau aplikasi  
akan memberi notifikasi otomatis kalau ada versi wajib.

</details>
